# XAUUSD-бот на GitHub Actions (бесплатно, без карты и без VPS)

Бот сканирует золото (M5/M15) каждые 5 минут и шлёт сетапы в Telegram.
Работает в облаке GitHub — ноутбук может быть выключен, какая угодно ОС.
Токен бота хранится в Secrets репозитория и наружу не попадает.

## Установка (~10 минут, всё через браузер)

1. Заведи аккаунт на github.com (бесплатно, карта не нужна).
2. Создай репозиторий: плюсик справа вверху -> New repository.
   Имя: xau-signal. Видимость: Public (у публичных репозиториев
   минуты Actions безлимитные; секреты всё равно защищены).
   Поставь галочку "Add a README file" -> Create repository.
3. Загрузи файлы из этой папки:
   - В репозитории: Add file -> Upload files.
   - Перетащи xau_signal.py и папку .github целиком
     (внутри должен получиться путь .github/workflows/xau-signal.yml).
   - Commit changes.
4. Добавь секреты: Settings репозитория -> Secrets and variables ->
   Actions -> New repository secret. Два секрета:
   - Имя: TELEGRAM_BOT_TOKEN, значение: токен бота (из файла
     xau-signal.env в папке ~/xau-vps на ноутбуке, строка после '=').
   - Имя: TELEGRAM_CHAT_ID, значение: 6412083673
5. Разреши запись: Settings -> Actions -> General -> Workflow
   permissions -> "Read and write permissions" -> Save.
   (Нужно, чтобы бот сохранял state кулдауна между запусками.)
6. Проверь: вкладка Actions -> "XAUUSD signal scan" -> Run workflow.
   Через минуту в Telegram придёт тестовое сообщение? Нет — обычный
   скан: в выходные рынок закрыт и бот молчит, это нормально.
   Чтобы проверить доставку, открой xau_signal.py на GitHub,
   ничего не меняя, нажми карандаш и закоммить — или скажи Hermes,
   он пришлёт тест через ноутбук.

## Как это работает
- Cron GitHub запускает скан каждые 5 минут (бесплатно, безлимитно
  для публичных репозиториев).
- state.json хранит кулдаун (не чаще 1 сигнала в час) и коммитится
  обратно в репозиторий, поэтому дублей не будет.
- .heartbeat — метка активности раз в сутки: GitHub отключает
  cron у репозиториев без активности 60 дней, метка это предотвращает.

## Честные ограничения
- GitHub может задерживать запуск на 5–30 минут при высокой нагрузке
  на свои серверы. Для сигналов M5 это минус: вход может прийти
  позже идеальной точки. Если задержки будут мешать — переезд на
  дешёвый российский VPS (~150–300 руб/мес, карты РФ принимают).
- Выходные: рынок закрыт, бот молчит (защита от устаревших данных).
- Время в сообщениях — UTC+04:30 (твоё), независимо от сервера.
